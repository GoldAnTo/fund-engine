# FundClaw 对话投研工作台原型

## 当前版本：V2 多角色工作台

使用 `fundclaw-team-workspace-v2.html`。它按用户提供的截图及主目录 `docs/superpowers/specs/2026-09-04-fundclaw-research-workbench-design.md` 对齐，替代 V1 的产品展示基准。V1 保留作历史比较，不再作为后续前端设计依据。

四个中央工作区分别为分析师-产业、分析师-财务、分析师-策略、质控审核员（AI）。每个区块显示自己的任务、状态、附件与证据；展开后显示资料边界、产出、依赖、阻塞、下一步与交接记录。右栏恢复为证据与来源、待解决问题、审查状态。支持按角色筛选、查看协作时间线、查看研究产出和定向补充要求。

所有内容都是本地演示。新建研究显示待建立范围、四角色等待分工与空证据，不复用旧研究产出；首条定向消息保留收件角色。样例附件只定位到演示材料，不提供假文件下载。AI 质控状态与人工审核分开。

验证：1536 × 1024 下四个专业角色同屏可见；390 × 844 无横向溢出，输入区在视口内。已操作检查角色展开、财务证据绑定、定向消息、角色筛选、12 条协作行动、4 类产出、审查 Tab 键盘导航、新线程空证据与收件角色保存。内联脚本语法与预览副本一致性检查通过。

重要的集成缺口：专业角色是任务归属维度，不是后端 P0 scope/evidence/analysis/compilation 执行角色的一对一换名。真实接入前需补专业角色的任务归属、证据/产出绑定和状态投影契约。本次只改隔离原型，没有改主目录 React 前端或后端模型。

## V1 历史版本

`fundclaw-research-workspace.html` 是自包含 HTML/CSS/JavaScript 交互原型。直接用浏览器打开即可；无需安装依赖，也无需研究引擎或模型凭证。

## 本轮可体验

- 对话发起演示研究、追加研究要求、查看前序问题与范围。
- 查看四个固定角色的职责、进度、下一步和阻塞原因。
- 从证据列表或草案引用打开样例原文定位。
- 演示“进行中 → 缺少证据 → 草案待人工复核”及重播。
- 桌面三栏工作台；窄屏切换研究列表、对话、团队与证据。

## 边界

所有公司、材料、事件和草案均为样例。操作不调用模型、不启动真实研究、不写入后端。新问题与历史只保存在当前页面内存中，刷新即重置；示例证据不会随自定义问题重新检索。不可将预览内容作为真实投研依据。

本原型不是已经接通的生产前端。页面中的“开发进度”以本分支后端提交 `03bf8446` 为基线：已有会话、研究和角色事件的存储基础；对话启动服务、原生任务事件投影、认证事件流与页面绑定仍需实现。

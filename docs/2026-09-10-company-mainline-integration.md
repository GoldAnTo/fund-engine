## 集成时修复的问题

- 运行校验器从当前仓库字面量迁移声明计算唯一 head，拒绝缺失父节点、多 head 和环；历史独立数据库的 `0062` 校验保留。
- GNU tar 空归档填充导致压缩率测试夹具误触保护，改用标准且可跨平台重现的夹具；生产归档压缩率上限保持不变。目录权限测试改用标准库读取权限。
- 真实 HTTP 验证改用有界的 30 秒启动等待；子进程退出即报告，并保留有界启动日志。
- PostgreSQL 并发测试在真正取得锁之后通知另一线程，避免测试调度竞争；生产锁代码保持不变。
- API 客户端接受已冻结 v1 结果中的有限科学计数法数值，例如 `0E-8`。输入格式、后端计算版本和保存内容哈希不变，非法及非有限结果继续拒绝。

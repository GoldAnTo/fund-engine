# 研究入口重设计：待确认方案

目标：用户无需先理解公司的身份模型、事件研究协议或后台默认策略，就能开始研究。沿用已认可的浅色纸面与深绿操作色，统一新建入口与研究库。

本文件及可交互 HTML 是设计评审材料。尚未修改正式前端、后端或数据库。页面中的提取与创建均为明确标记的示例交互。

## 已核实的问题

1. 用户当前打开 `/`，这是旧事件工作台。新建表单要求标题、原始材料、研究问题、3–5 个候选因素和创建人；来源链接另为选填。系统要求用户先完成部分研究工作。
2. `/research` 又是另一套公司入口；从研究库搜索跳到新建页后会重新搜索，随后还需点击公司并确认一整页不可编辑的默认设置。
3. 同一公司和其证券分开显示，Company、Security、外部标识、默认策略说明占据主流程；关联证券在多公司搜索结果中还可能被错误地共同展示。
4. 首屏没有说明当前实际可用范围。后端当前仅支持 Alphabet 自动公司研究，资料截止被固定到历史边界；搜索到对象不代表能研究。

## 比较过的做法

| 方案 | 收益 | 局限 |
| --- | --- | --- |
| 单页统一入口，两个明确起点（推荐） | 首页和新建一致，按公司/材料开始，辅助信息按需展开 | 需要整理根路由及研究库，接入已有材料提取接口 |
| 只压缩公司新建页 | 改动最小，立即消除重复搜索与确认页 | 用户默认进入的旧事件表单依然复杂，入口分裂仍存在 |
| 完全自由的对话式入口 | 初次输入容易 | 对象识别、资料边界和研究提纲容易隐形，与持续研究工作台的既有定位不符 |

## 推荐流程与页面

左侧固定新建、研究库、最近打开；主区域保留一个输入任务，下面可以继续已有研究。采用用户日常在明亮办公环境中读材料、开研究的浅色工作界面。视觉锚点是已认可的七页原型；交互参考标准搜索选择框、Notion 页面创建和 Linear 的紧凑表单，而非另造一套品牌样式。

### 研究公司

- 输入公司名称或代码，结果随输入更新，点击选中。证券归属以所选公司的 preview 响应为准，合在公司信息行展示。
- “特别想了解什么”选填。快捷方向是可编辑的提示，不增加必填模板或研究类型。
- 选中后自动预览并在本页显示实际资料截止、关联证券。期限、币种等默认设置折叠展示；日期不折叠，不写“截至今天”。
- 一个“开始公司研究”主按钮，直接进入已有工作台。preview 与 initialize 的身份、输入、哈希校验仍保留，用户不再经过专门的默认方案确认页。
- 不支持的公司明确说明可用范围，并提供材料入口。相同公司、相同范围和关注问题的重复请求，应通过认证的已有研究身份继续；不能仅凭公司名称跳入不相同的问题。

### 从材料开始

- 首屏只要求粘贴原始正文。关注问题及引用链接选填。创建人不再让用户手填，服务端使用可信租户审计主体，不能假造具体人名。
- 点击“整理研究提纲”，使用已存在的 `/api/v1/event-research/extract`。该接口只收正文与来源链接；若用户填写关注问题，则将其作为待确认核心问题保留，而不是假装它已经影响提取模型。
- 在同一主区域先呈现阅读式提纲，包含标题、核心问题、3–5 个待验证因素；需要调整时展开“修改这份提纲”。用户按“确认提纲并开始研究”提交。这个明确动作确认研究起点，不自动确认后续投资结论，也不另加确认复选框。
- 原始材料保留，可返回修改。修改材料使旧提纲失效；提取失败可重试或进入手动提纲编辑；创建失败保留当前编辑并复用同一请求的幂等键。
- 仅贴链接、文件拖拽和任意公司联网研究不列作已支持功能。当前引用链接只保留出处，提取依赖粘贴正文。

### 研究库与路由

- 根首页与公司研究库应使用相同导航、状态语言和新建入口；研究列表标明公司或材料研究，同时保留真实状态与继续入口。
- 旧 `/?caseId=...`、公司 `/research/projects/...`、事件市场页及研究档案的深链接继续可用。不能把带 caseId 的历史链接重定向成空白创建页。
- 当一类列表请求失败时，单独显示重试；不能把加载失败显示为“没有研究”。

## 落地所需工作

| 层次 | 工作 |
| --- | --- |
| 前端 | 统一入口/导航，搜索选择交互，省去公司独立预览确认页，材料提取客户端及提纲核对，创建状态和错误恢复 |
| 后端小改 | 已认证租户作为默认事件创建审计主体；若现有冲突响应不足以定位已有公司研究，补受租户限制的安全恢复信息 |
| 保留 | 研究来源、模型、幂等与哈希边界；公司和事件研究各自的领域数据及后续工作台 |
| 后续另做 | 任意公司研究、上传/链接正文自动提取、跨设备创建草稿恢复、正式模型假设复核 |

## 状态与验收

需要覆盖：初次进入、输入/选择/清空公司、无结果、不支持对象、预览中和失败、提取中和失败、修改原材料、提纲编辑、创建中/失败/成功、重复提交、迟到响应、返回保留输入、未登录或身份失效。

公司常规路径为选择一次、开始一次；关注问题可空。材料常规路径为粘贴正文、整理、核对提纲后开始。所有前置字段都有实际用途，不要求用户填身份或后台参数。宽屏与窄屏保持主按钮清晰可见，键盘可完成核心路径。

- 示例明确标注，所有按钮不调用正式 API；原有研究数据未改动。

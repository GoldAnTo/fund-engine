# FundClaw 原型一致性修复

依据用户已确认的 `docs/prototypes/fundclaw-team-workspace-v2.html`，修复真实工作台偏离原型的问题。沿用现有原型的布局与交互，不另行设计产品形态。

## 验收基准

- 桌面端保持左侧研究列表与关键问题、中央角色工作区、右侧证据上下文三栏。1440px 下左栏约 250px、右栏约 365px。
- 标题压缩为单行概览，可展开完整请求；研究范围使用服务端已冻结字段，没有字段时明确待确认。
- 中央依次为范围、研究对话 / 协作时间线 / 研究产出切换、角色筛选、可独立滚动的内容与固定底部输入框。
- 默认同时呈现产业、财务、策略、AI 质控四张紧凑工作卡。摘要、实际状态、实际下一步 / 缺口、产出与引用入口可见；全文、依赖版本与模型调用按需展开。
- 右栏持续展示证据与来源 / 待解决问题 / 审查状态。引用打开受授权的冻结原文；问题可定向交给负责角色；AI 检查与已保存人工复核严格区分。
- 历史版本只读；保留暂停、恢复、停止、失败重试、定向消息、人工复核以及精确旧任务依赖导航。
- 只从实际任务、产出、证据、复核记录投影信息。不复制原型中的演示公司、附件、状态、时点或问题。
- 新研究页延续同一工作台骨架。窄屏提供明确面板切换；320px 到桌面无横向溢出，短屏能访问输入与引用。

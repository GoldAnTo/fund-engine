# 事件影响穿透设计：事件到中国公司、A 股与基金

## 目标

让事件研究的关键因素从“新闻解释”落到可审计的资产影响链。事件来源可以是国内或海外；首期研究对象限定为 A 股和中国基金。海外公司与未上市公司用于解释传导机制和提供证据，不被伪装成可交易资产或基金暴露。

系统要能回答：

1. 国内或海外事件通过哪些公司关系影响中国公司；
2. 哪些中国 A 股的经营与市场数据支持或反驳这种影响；
3. 哪些中国基金以真实、带时点的持仓暴露于这些 A 股；
4. 哪个环节尚无足够证据，因此不能形成结论。

系统输出研究判断、证据强弱和暴露范围，不输出买卖建议、目标价或收益承诺。

## 范围与非范围

本轮在现有“结论优先事件研究工作台”中增加影响穿透能力：

- 国内或海外事件及其相关公司作为冲击源；
- 自动识别事件公司、供应商、客户和竞争对手；
- 自动解析中国公司、上市证券及中国基金持仓；
- 按严格数据时点和来源准入规则计算证据覆盖和基金暴露；
- 支持研究员修正高影响公司关系和关键证据。

首期不做全球证券和海外基金的暴露计算，也不将缺少可核验来源的 AI 关系作为结论依据。

## 四层影响链

每个关键因素必须以同一个 `ImpactTrace` 读模型展示四层链路。

```text
事件与相关公司（国内或海外）
  → 中国公司传导（上市 / 未上市）
  → A 股经营与市场验证
  → 中国基金真实持仓暴露
```

### 1. 事件与相关公司

保留事件原文、发布日期、来源准入状态与命题证据。事件可由国内政策、上市公司公告、产业供需变化或海外公司/宏观新闻触发。相关公司可作为事件主体、客户、供应商或竞争对手；若主体没有中国可交易证券映射，它只承担传导和证据角色，不产生中国资产暴露。

### 2. 中国公司传导

系统先生成候选 `CompanyImpactRelation`：

- `supplier`（供应商）；
- `customer`（客户）；
- `competitor`（竞争对手）；
- `partner`（合作伙伴）；
- `industry_peer`（行业对照）。

每个候选包含影响方向、机制说明、关系来源、有效时间、置信状态和人工审核结果。没有来源或仅为 AI 推断的候选保持“待核验假设”，不会进入结论。

未上市公司是完整的公司节点，可凭订单、产能、招投标、客户关系、官方披露和可信公开报道验证传导；但没有 `Stock` 映射时不可进入股票收益、估值或基金暴露计算。

### 3. A 股验证

中国上市公司映射到现有 `Company → Stock → ValuationSnapshot` 账本。一个公司影响要成为“已验证影响”，至少需要两类、且时间点不晚于结论基准日的数据：

1. 经营数据：公告、财报、订单/收入线索、毛利率、产能或业绩指引；
2. 市场数据：事件窗口收益、成交量、估值变化、相对行业/指数表现。

若只有行情数据，状态为“市场反应已观察”；若只有经营线索，状态为“经营传导待市场验证”；两者都不足时不得标记为已验证。

任何事件对中国公司的弱关联都必须提供行业、同业或宏观对照，避免将整体市场波动误归因给事件。跨境事件还需额外说明其跨境传导机制。

### 4. 中国基金暴露

只对“已验证影响”的中国 A 股计算基金暴露。计算使用现有 `HoldingDisclosure`：

```text
基金暴露 = 最新可用披露中该基金对已验证 A 股的持仓权重之和
```

每个基金结果必须显示报告期、披露日、数据来源、已覆盖持仓数量和总覆盖率。披露过期、缺失、基金无法穿透或覆盖率低于阈值时，状态为“不可计算 / 仅部分覆盖”；不得给出精确基金影响数值。

## 自动研究和人工边界

事件创建或因素范围更新后，系统按顺序自动执行：

1. 从可采纳事件证据中抽取公司和候选关系；
2. 解析公司实体、别名和上市证券映射；
3. 搜索并审核关系来源，标注传导机制；
4. 拉取 A 股公告、财务、行情、估值及同业对照数据；
5. 读取中国基金带时点的持仓披露并计算覆盖率；
6. 对每个因素更新公司、股票和基金层的证据缺口；
7. 仅在高影响关系、关键来源、关键证据或结论草案需要判断时创建人工待办。

研究员不需要逐条启动任务；可在影响穿透页纠正候选公司关系、补充来源、审核高影响证据，或调整因素范围。范围变更保持既有 append-only 审计、历史证据和已发布结论，自动启动新范围研究；旧范围输出不得进入新结论。

## 工作台与交互

现有结论优先工作台保留首屏判断和唯一主动作。新增“影响穿透”层：

1. 首屏展示结论置信度、已核验证据、待审核证据、已验证 A 股数和基金持仓覆盖率；
2. 研究员选择一个关键因素后，下钻为事件来源、公司传导、A 股验证、基金暴露四段；
3. 公司清单显示公司类型（上市/未上市）、关系、机制、证据状态、数据状态和可展开来源；
4. A 股条目区分经营验证、市场验证、同业对照与缺口；
5. 基金条目显示最新披露日期、持仓权重、覆盖率和是否可计算；
6. 对无效来源、披露过期、映射失败和未上市公司，使用明确状态文本，不通过空白、估算数或绿色成功状态掩盖不确定性。

系统研究中时，页面只说明正在补齐的环节和可查看的依据；不要求用户盲目点击“采纳”或启动后台任务。

## 数据来源与可追溯性

中国市场数据优先使用可审计的金融数据接口和已入库账本：

- A 股：证券基本信息、公告、财务报表、日行情/事件窗口、估值快照、行业和指数对照；
- 中国基金：基金基本信息、历史净值（用于展示而非替代持仓）、股票持仓披露、报告期与发布日期；
- 公司传导：公司公告、财报、客户/供应商披露、招投标、官方站点及经来源准入的新闻/研究材料。

所有派生行保留原始来源、工具/接口标识、抓取时间、数据基准日和定义。实时行情与冻结研究账本分开处理；结论只能引用在其基准日可见的数据。

## 异常状态

| 情况 | 可见状态 | 系统行为 |
| --- | --- | --- |
| 公司无法解析 | 待确认公司 | 继续搜索别名和关系来源；不计入资产层 |
| 关系只有 AI 推断 | 待核验假设 | 不进入结论或基金计算 |
| 仅有行情数据 | 市场反应已观察 | 搜索经营侧证据 |
| 仅有经营数据 | 经营传导待市场验证 | 补事件窗口和对照数据 |
| 未上市公司 | 传导节点 | 不计算股票或基金暴露 |
| 基金披露过期/不足 | 不可计算或部分覆盖 | 展示日期与覆盖率，不显示精确影响 |
| 当前范围证据不足 | 暂不能下结论 | 显示缺口和系统下一次尝试 |

## 验收标准

1. 国内或海外事件都能建立到中国公司、A 股和中国基金的可追溯影响链；
2. 供应商、客户、竞争对手和未上市公司均可作为公司节点，且关系具备来源和状态；
3. 未上市公司没有股票映射时不会出现在股票收益或基金暴露结果中；
4. A 股“已验证影响”同时需要经营数据和市场数据，并有同业/行业对照；
5. 基金暴露只使用可用持仓披露，明确报告期、披露日与覆盖率；
6. 低覆盖、过期披露、无效来源和映射失败不产生伪精确结论；
7. 因素或公司关系调整后，历史审计保留，自动研究在新范围内继续；
8. 影响穿透页在窄屏下仍能依次阅读结论、因素、公司、股票和基金信息；
9. 自动任务、异常和人工审核路径具有后端集成测试及浏览器端到端测试。

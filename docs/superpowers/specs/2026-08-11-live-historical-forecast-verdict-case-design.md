# 聚源真实历史预测单案例闭环设计

## 目标

将一个可复核的真实聚源历史研究案例写入当前 Research OS，并将同一次运行的结果展示在对应 Case 的“市场与表达”页。范围是一个完整闭环，不扩展为批量预测评分、投资建议或实时基金持仓产品。

## 已选案例与来源

标的为火星人 `300894.SZ`，核对指标为 2024 年归母净利润。

| 环节 | 已读取的聚源记录 | 冻结字段 | 用途 |
| --- | --- | --- | --- |
| 历史研报预测 | 广发证券《火星人(300894)：23年业绩承压 分红比例提升》，2024-04-28，`FinancialResearchReport` 查询 `火星人 2024年 归母净利润 预测 研报` | 原始响应、报告标题、机构、发布时间、原文定位、内容 hash、`available_at` | 只作为研报预测主张：2024 年归母净利润 3.0 亿元。 |
| 后续公司公告 | 火星人《2024年年度报告摘要》，2025-04-23，`AnnouncementData` 查询 `火星人 2024年年度报告` | 原始响应、公告标题、发布时间、原文定位、内容 hash、`available_at` | 只作为后续实际指标：2024 年归母净利润 11,151,200 元。 |
| 股票映射 | 火星人 `300894.SZ` | 审核理由、来源与关联时间 | 将验证结果表达至已审核股票，不推导交易动作或价格因果。 |
| 基金历史暴露 | 南方中证1000ETF `512100`，聚源 `FinQuery` 查询 `火星人 300894 2024年第四季度 基金持仓`，报告期 2024-12-31，持有 135.58 万股；对应基金 2024 年年报由 `AnnouncementData` 于 2025-03-31 返回 | 原始结构化响应、报告期、披露日、采集日、来源契约、覆盖状态 | 只展示为历史披露暴露。聚源返回的基金年报摘要不包含该股票完整持仓明细，因此覆盖状态必须是 `partial`，不得表示实时仓位、完整组合权重或基金看多。 |

数值以冻结的最小货币单位 CNY 存储：预测值 `300000000`，实际值 `11151200`。页面可同时显示换算后的亿元或万元，但必须保留原始值和单位。

## 不可变运行链

```text
冻结聚源研报原文
  -> 审核 ReportClaim（forecast）
  -> 审核 KeyFactor（2024 年归母净利润）
  -> 冻结 ForecastTargetVersion（预测、基线、规则）
  -> 冻结聚源年报摘要与 ActualMetricObservation
  -> 生成 ForecastEvaluationCandidate
  -> 人工发布 ForecastVerdict
  -> 审核 Company / Stock 关联
  -> 冻结 HoldingDisclosure 与基金报告来源
  -> Market Expression 读取模型
```

1. 预测、基线、实际、机器候选、人工 verdict 均为追加式记录；任何重跑产生新记录，不覆盖旧记录。
2. `available_at` 分别取冻结研报与公告的实际发布时间；读取时按 cutoff 过滤，禁止以后来的年报回写到早期时点。
3. 机器规则固定为 `forecast-numeric-v1`：同实体 `300894.SZ`、同单位 `CNY`、同期间 `2024-01-01` 至 `2024-12-31`，`within_tolerance`，相对容差 `0.10`。
4. 实际值与 3.0 亿元偏离超过 10%，机器候选应为 `contradicted`。候选不能进入正式页面结论；只有研究员以 `confirmed` 发布后，页面显示“预测未兑现”。
5. 若来源、权限、实体、单位、期间、可得时间或基金报告期匹配失败，保持可恢复的待处理状态，不创建正式 verdict 或持仓披露。

## 页面呈现

在该真实 Case 的“市场与表达”页，选中关键因素时显示“历史预测验证”段，按时间顺序展示：

1. 研报预测：数值、机构、发布时间、冻结原文链接；
2. 冻结基线：基线值、比较规则、适用期间；
3. 后续公告实际：数值、公告发布时间、冻结原文链接；
4. 自动判据：规则版本、输入快照、机器候选状态；
5. 人审 verdict：确认结果、研究员、理由、审核时间；
6. 股票与基金表达：已审核股票关联，以及带报告期、披露日、采集日、覆盖状态的基金历史暴露。

页面不得使用“研报导致股价”“买入”“实时持仓”“完整持仓权重”等表述。股票价格观察如被纳入，必须单列为观察，不能作为预测验证或因果证明。

## 运行可见性

本次 live run 在 Case 的“监测与运行”页保留逐步记录：调用的聚源工具和查询、返回数量、冻结的文档 hash、允许展示的来源契约、字段换算、规则输入、机器候选与人工发布动作。原始聚源材料在许可范围内通过当前 Case 原文资料入口查看；运行日志不以黑盒摘要替代这些记录。

## 验收

1. 一条 live-run 测试从聚源读取并冻结三类原始材料，创建上述不可变链，且实际 API 读模型返回已发布 `contradicted` verdict。
2. 测试断言原始预测 `300000000 CNY`、实际 `11151200 CNY`、10% 容差、`forecast-numeric-v1`、人审理由和两份冻结来源均可追溯。
3. 测试断言 `300894.SZ` 与 `512100` 均关联到同一 Case；基金记录显示 `2024-12-31`、`2025-03-31`、`partial`，且没有实时持仓或因果语言。
4. 前端端到端测试从真实 Case 路由读取，不使用 `?client=mock`，能够打开预测、公告、verdict、股票和基金历史披露来源。
5. 对一个同案例但错误单位、错误期间或 cutoff 早于公告的读写测试必须被拒绝或只返回非正式状态。

# 聚源真实历史预测单案例闭环设计

## 目标

将一个可复核的真实聚源历史研究案例写入当前 Research OS，并将同一次运行的结果展示在对应 Case 的“市场与表达”页。范围是一个完整闭环，不扩展为批量预测评分、投资建议或实时基金持仓产品。

## 已选案例与来源

标的为工业富联 `601138.SH`，核对指标为 2024 年归母净利润。研报中提出的 AI 服务器与高速网络产品升级作为独立关键因素验证，不把它们与利润预测混为一条事实。

| 环节 | 已读取的聚源记录 | 冻结字段 | 用途 |
| --- | --- | --- | --- |
| 历史研报预测 | 海通证券《工业富联(601138)：盈利整体平稳增长 AI业务表现强劲》，2024-03-25，`FinancialResearchReport` 查询 `工业富联 2024年 归母净利润 预测 研报` | 原始响应、报告标题、机构、发布时间、原文定位、内容 hash、`available_at` | 只作为研报预测主张：2024 年归母净利润 251.49 亿元。 |
| 后续公司公告 | 工业富联《富士康工业互联网股份有限公司2024年年度报告》，2025-04-30，`AnnouncementData` 查询 `工业富联 2024年年度报告` | 原始响应、公告标题、发布时间、原文定位、内容 hash、`available_at` | 只作为后续实际指标：2024 年归母净利润 232.16 亿元。 |
| 关键因素后续验证 | 同一研报中 AI 服务器与高速交换机升级的判断；同一份 2024 年年报中的云计算收入、AI 服务器收入增速、400G/800G 交换机信息 | 逐项原文定位、主体、观察期、指标口径与审核理由 | 分别验证云计算收入 3193.77 亿元、同比 +64.37%，AI 服务器收入同比超过 +150%，以及 400G/800G 交换机同比数倍增长。它们支持研究逻辑，不自动构成股价因果。 |
| 股票映射 | 工业富联 `601138.SH` | 审核理由、来源与关联时间 | 将验证结果表达至已审核股票，不推导交易动作或价格因果。 |
| 基金历史暴露 | 华夏中证5G通信ETF `515050`，聚源 `FinQuery` 查询 `查询基金515050 2024年第4季度公开披露的股票持仓明细，包括股票代码、股票名称、持仓权重、报告期`，报告期 2024-12-31；工业富联持仓市值占资产净值 5.33%。对应 2024 年年报由 `AnnouncementData` 于 2025-03-31 返回 | 原始结构化响应、报告期、披露日、采集日、来源契约、覆盖状态 | 只展示为历史披露暴露。结构化持仓明细提供该时点权重，年报用于核对基金、报告期和披露时间；覆盖状态仍为 `partial`，不得表示实时仓位、完整组合权重或基金看多。 |

数值以冻结的最小货币单位 CNY 存储：预测值 `25149000000`，实际值 `23216000000`。页面可同时显示换算后的亿元，但必须保留原始值和单位。

## 不可变运行链

```text
冻结聚源研报原文
  -> 审核 ReportClaim（forecast）
  -> 审核 KeyFactor（AI 服务器与高速网络产品升级）
  -> 冻结 ForecastTargetVersion（预测、基线、规则）
  -> 冻结聚源年报摘要与 ActualMetricObservation
  -> 生成 ForecastEvaluationCandidate
  -> 人工发布 ForecastVerdict
  -> 审核 Company / Stock 关联
  -> 冻结 HoldingDisclosure 与基金报告来源
  -> Market Expression 读取模型
```

1. 预测、基线、实际、机器候选、人工 verdict 均为追加式记录；任何重跑产生新记录，不覆盖旧记录。
2. `available_at` 分别取冻结研报与公告的实际发布时间；读取时按 cutoff 过滤，禁止以后来的年报回写到早期时点。
3. 机器规则固定为 `forecast-numeric-v1`：同实体 `601138.SH`、同单位 `CNY`、同期间 `2024-01-01` 至 `2024-12-31`，`within_tolerance`，相对容差 `0.10`。
4. 实际值与 251.49 亿元偏离约 7.69%，机器候选应为 `supported`。候选不能进入正式页面结论；只有研究员以 `confirmed` 发布后，页面显示“预测在容差内兑现”。
5. 若来源、权限、实体、单位、期间、可得时间或基金报告期匹配失败，保持可恢复的待处理状态，不创建正式 verdict 或持仓披露。

## 页面呈现

在该真实 Case 的“市场与表达”页，选中关键因素时显示“历史预测验证”段，按时间顺序展示：

1. 研报预测：数值、机构、发布时间、冻结原文链接；
2. 冻结基线：基线值、比较规则、适用期间；
3. 后续公告实际：数值、公告发布时间、冻结原文链接；
4. 自动判据：规则版本、输入快照、机器候选状态；
5. 人审 verdict：确认结果、研究员、理由、审核时间；
6. 股票与基金表达：已审核股票关联，以及带报告期、披露日、采集日、覆盖状态的基金历史暴露。

页面不得使用“研报导致股价”“买入”“实时持仓”“完整持仓权重”等表述。股票价格观察如被纳入，必须单列为观察，不能作为预测验证或因果证明。

## 运行可见性

本次 live run 在 Case 的“监测与运行”页保留逐步记录：调用的聚源工具和查询、返回数量、冻结的文档 hash、允许展示的来源契约、字段换算、规则输入、机器候选与人工发布动作。原始聚源材料在许可范围内通过当前 Case 原文资料入口查看；运行日志不以黑盒摘要替代这些记录。

## 验收

1. 一条 live-run 测试从聚源读取并冻结三类原始材料，创建上述不可变链，且实际 API 读模型返回已发布 `supported` verdict。
2. 测试断言原始预测 `25149000000 CNY`、实际 `23216000000 CNY`、10% 容差、`forecast-numeric-v1`、人审理由和两份冻结来源均可追溯。
3. 测试断言 AI 服务器和高速网络产品升级的关键因素由后续年报指标逐项验证，且 `601138.SH` 与 `515050` 均关联到同一 Case；基金记录显示 `2024-12-31`、`2025-03-31`、5.33%、`partial`，且没有实时持仓或因果语言。
4. 前端端到端测试从真实 Case 路由读取，不使用 `?client=mock`，能够打开预测、公告、verdict、股票和基金历史披露来源。
5. 对一个同案例但错误单位、错误期间或 cutoff 早于公告的读写测试必须被拒绝或只返回非正式状态。

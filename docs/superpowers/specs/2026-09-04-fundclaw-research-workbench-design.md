# FundClaw 单页研究工作台设计

## 1. 功能概述

将现有 Fund Engine 多路由前端整体替换为一个单页、桌面优先的 FundClaw 投资研究 Agent Gateway。它服务于研究员持续推进一个行业研究，而不是在多个传统后台页面之间跳转。

本轮仅使用本地 mock 数据，不连接现有 API，不保留旧页面或旧路由兼容层。

## 2. 核心行动

研究员能在同一屏内查看研究范围、调度不同分析角色、追踪任务推进，并核对右侧可追溯证据。

## 3. 设计方向

- 色彩策略：克制型。暖白纸张底色与带绿墨色文字为主，深绿只用于当前上下文和主要行动，绿、琥珀、红仅表达状态。
- 使用场景：研究员在明亮办公室的宽屏显示器前审阅行业研究，注意力在证据、分析任务和待决问题之间切换，需要高密度但安静的界面。
- 锚点：用户提供的 FundClaw 截图、专业研究案头、线性任务流。
- 视觉参考：用户给出的高保真截图为北极星；不额外生成视觉探针，避免引入与其不一致的新视觉方向。

## 4. 范围

- 保真度：生产级前端界面。
- 广度：一个完整研究工作台单屏，替换全部旧页面。
- 交互：本地 mock 驱动，线程选择、Tab、筛选、证据与任务卡选择、折叠和底部输入反馈可用。
- 时间意图：先完成一个高保真、可演示、可扩展的前端基座。

## 5. 布局策略

固定顶栏下采用三栏工作区：

1. 左栏（约 264px）：研究空间、协作入口、可选研究线程与关键决策。
2. 主栏（流体）：标题与行动区、研究范围标签、内容 Tab、任务筛选、按时间组织的研究目标及 Agent 执行卡，底部为发送输入区。
3. 右栏（约 365px）：证据与来源、待解决问题、审查状态三个上下文 Tab，以及相关性排序的证据卡。

内容由细分隔线、紧凑标签与连续时间轴组织，不使用指标卡网格。宽度低于 1180px 时，两侧栏转为可展开的覆盖面板，主栏始终保持工作焦点。

## 6. 状态

- 默认：截图中的在研状态，显示四类任务与证据卡。
- 线程切换：更新标题、研究范围和任务内容，并保留当前工作台结构。
- 筛选：按全部、结论、求证、证据、决策过滤中栏流。
- 右栏 Tab：在证据、待解决问题、审查状态间切换。
- 仅看待办：显示需要研究员参与的项目。
- 空态：说明如何新建研究与添加研究目标。
- 加载态：按三栏结构显示骨架，不使用中心转圈。
- 移动/窄屏：左、右栏从边缘抽屉进入，避免压缩主内容。

## 7. 交互模型

- 左侧线程可选并更新当前研究。
- 顶部返回、分享、导出与新建研究提供即时 mock 反馈。
- 主栏 Tab 和任务筛选按钮保持可见选中状态。
- 任务卡可折叠，附件、引用数与任务状态可读。
- 右侧证据可被选中，显示为当前上下文；右栏 Tab 可切换。
- 底部输入框可提交，追加一条本地研究员消息。
- 所有交互控件支持键盘焦点和明确的文字标签。

## 8. 内容要求

使用与参考图相同类型的半导体国产化研究 mock 内容，包括研究标题、研究范围、四个分析角色、文件附件、公司证据、待决问题与审查状态。文案以中文为主，英文仅保留产品必要术语（Agent Gateway）。

## 9. 技术策略

- 用 React + TypeScript 重新组织为单页工作台组件与本地 mock 数据模块。
- 删除对现有 ResearchClient、旧页面和旧路由的 UI 依赖；入口只渲染新工作台。
- 保留 Vite、TypeScript、Vitest 与现有构建配置。
- 使用语义 HTML、CSS 变量和内联 SVG 图标，不新增重量级 UI 依赖。

## 11. 非目标

- 不连接真实 API 或实现后端写入。
- 不复刻旧的案例、资料库、审核、公司和主题页面。
- 不生成投资建议、目标价、仓位或买卖操作。
- 不将 mock 状态描述为真实人工审核或实时证据。

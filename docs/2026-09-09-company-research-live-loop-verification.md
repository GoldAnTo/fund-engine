本轮基于 `codex/company-research-prototype-delivery`，沿用现有公司研究入口。目标是 Alphabet 的历史资料研究；资料边界为 `2026-08-25T23:59:59Z`，不代表最新披露。

## 已实现的实际路径

初始化公司和关注问题 → 官方原文获取与哈希核验 → 冻结本次输入片段 → LLM 生成带原文引用的分析 → 待审初稿可阅读 → 数字证据逐项审核 → 确定性模型 → 确认备忘录 → 保存、回放、导出。

初稿独立保存，备忘录引用初稿及来源哈希。来源、模型输入、模型输出、用量和运行身份可以相互核对。失败、任务取消、过期任务和提交回滚保留已发生的模型调用收据，不留下可用的半成品。冻结版本使用当时的研究范围，不依赖之后修改的工作区指针。

模型输出只提供定性分析及候选假设。正式预测与估值仍受原有证据和确定性计算约束；缺少输入时保留不可回答状态。

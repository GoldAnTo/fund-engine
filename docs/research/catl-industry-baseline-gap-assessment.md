# CATL 行业基线缺口评估（研究记录，不是投资结论）

**研究问题：** 在历史截止日 `2025-05-15T15:59:59Z` 前，是否存在可公开定位、可复现且权限足够的全球/中国电池产能、有效产能或利用率、需求，以及价格/成本基线，以安全推进 CATL 的正式机制和行业状态？

**结论：不能推进正式机制或行业状态。** 截止日前的权威公开资料足以补充若干公司事实和宏观/行业背景，但没有给出同一口径、同一地理范围、同一期间的中国或全球“名义产能—实际可用产能—产出/需求”完整链条。尤其不能把公司产能利用率、全球容量份额、中国锂电池总产量、动力电池装车量相除，伪造一个“行业利用率”。价格资料也不足以把原材料均价可靠地传导为 CATL 单位成本或产品 ASP。

这份记录遵循“缺失即缺失”原则：下面的发现可作为下一版冻结基线的候选证据，不能追溯性改写现有的 evidence-only 版本。

## 口径和使用规则

- **名义产能（nameplate capacity）**：生产线设计/额定的年度电芯产能，不等于可交付产出。
- **报告利用率**：公司披露的 `产量 / 产能` 或公司定义的产能利用率；可记录为公司运营事实，不自动等于可比行业有效产能。
- **有效产能**：若要进入 IndustryState，必须有明示定义（投产、爬坡、良率、停产、产品结构、地域和期间）及可追溯计算，而不是仅用名义产能乘一个任意比例。
- **需求/装机/出货/产量不能混用**：装车量是装入车辆的量；销量是公司售出；产量是制造输出；IEA 的需求是按销售车辆的电池容量估算并明确排除库存。它们可并列解释，不能不加边界地相除。
- 下列“可使用”均仅指在冻结研究中保存**定位、时间、哈希（适用时）及派生观察值**的权限；不代表可把受版权或第三方数据集全文入库。

### 有效产能/利用率：存在 2023 年的高权威背景，不存在可校准的 2024 年行业基线

IEA 的 [*Global EV Outlook 2024*](https://www.iea.org/reports/global-ev-outlook-2024)由 IEA 于 **2024-04-23** 发布并采用 **CC BY 4.0**。其[电池章节第 91–117 行](https://www.iea.org/reports/global-ev-outlook-2024/trends-in-electric-vehicle-batteries?os=0)称：中国在 **2023 年**（不包括便携电子产品）使用的最大电芯产出低于 40%，同时说明其产能/贸易分析依赖 Benchmark Mineral Intelligence 和 EV Volumes，且不考虑储能、便携式应用或库存。

这是一条可引用的、跨行业的 2023 年利用率**方向性背景**，可显示过剩产能假说不是凭空产生；由于其为“低于 40%”的上限、范围排除了产品类别且没有公开的厂级分母/分子，不能把它正则化为精确数值、不能外推到 2024 年，也不能作为 CATL 或中国 2024 年有效产能的输入。其公开 IEA 表述可按 CC BY 4.0 引用；底层 Benchmark/EV Volumes 原始数据的使用权并未由此取得。

**行业状态放行决定不变：** 没有发现截至 2025-05-15 可公开定位且可复现的中国 2024 年名义电芯产能与同口径实际产出/有效产能定义。IEA 的 2023 年背景和公司级 CATL 利用率均不足以 formalize “产能 → 利用率 → 价格”机制，或创建数值 IndustryState。

## 对六条候选机制的影响

1. **EV/储能需求 → 电池出货：** IEA 和中国装车/生产数据使“需求存在且增长”可被证据化；但装车、销售、生产和库存的不同定义阻止用单一系数正式校准。
2. **名义产能 → 有效产能 → 利用率 → 价格：** CATL 年报允许公司级的事实锚点；缺少行业同口径基线和良率/爬坡信息，不能 formal。
3. **材料成本 → ASP/单位毛利：** 原料均价和价格趋势可做背景；缺少 BOM 和合同/滞后结构，不能 formal。
4. **认证/海外产能 → 可得份额/盈利：** 本轮没有获得可量化、可反证的截至日证据，仍是候选。
5. **Capex/折旧/营运资本 → FCF：** 年报可提供公司的财务锚点，但本轮没有完成独立的段级营运资本和折旧桥，不能 formal。
6. **客户议价与供给过剩反模型：** IEA 的名义容量远高于需求、价格下降和利润受压的背景与其方向一致，但不构成对 CATL 边际利润的识别。

## 放行决定与下一步

**当前决定：维持 `not_answerable` 和 `wait_for_validation`。** 已将 548.4 GWh 政府保存页及其派生观察值的 `published_at`/`first_available_at`/`available_at` 保守更正为 2025-01-20；内容中所称的联盟 2025-01-13 发布仍只是待独立原始来源验证的叙述。可安全做的是创建一个新的历史基线候选，明确记录 CATL 公司级 `reported` 产能、产量、利用率和销量事实。它不会自动完成 IndustryState，也不会提升任何候选 MechanismPack。

**推进 IndustryState 的最低新增证据：**

1. 一套同口径的中国（或明确的全球）2024 名义电芯产能、实际产出/需求和可用产能定义；
2. 每项指标的发布时点、可得时点、精确定位、许可/展示政策、修订政策；
3. 独立审查者对“产能—利用率—价格”因果链的方向、滞后、适用范围、反例和 falsifier 的确认；
4. 不把商业数据库的不可再发布厂级数据作为无来源的 JSON 数字。

在这些条件满足前，最深且最诚实的交付是：可回放的事实、明确的缺口、候选机制及其可证伪条件，而不是一个数字丰富但无法识别的行业模型。

# FundClaw 持续公司研究：实施与验收记录

日期：2026-09-09。目标：以持续公司研究组织事件调查、资料研究、资料更新与监控，并修复反复刷新。工作树：`.worktrees/fundclaw-gateway-p0-plan`。本记录与此前原型一致性检测互补，不将此前整个项目的未提交改动归为本轮新增。

## 已实施的主线

公司档案 → 建立研究基线 → 追加事件 / 资料 / 更新任务 → 后台创建真实研究 → 复用三栏四角色工作台 → 人工选择采用版本 → 后续研究读取该版本作为待重新核验的历史背景。

- 公司档案保存名称、市场、可选代码与长期研究重点，按认证主体和租户私有隔离；创建档案本身不调用模型。
- 事件、补充资料和更新任务持久排队，由独立公司研究 worker 调用现有 ResearchGateway，再进入原生采集和专业角色服务。页面关闭后队列继续运行。
- 已有会话可关联至公司档案，不修改其原始研究范围或专业结果。研究内提供返回公司档案入口。
- 采用版本记录确切的会话、run spec、团队版本及四项输出，不随新任务完成自动替换。显式打开旧版本时，不因后台团队升级而跳到新版。
- 监控默认关闭；配置后按北京时间每日 20:00 或每周一 20:00 派发资料更新，按时间窗去重，有未完成活动时限制堆积。暂停停止新派发，已派发任务保持实际状态。
- 前端与生产同源代理只开放精确的新接口。写操作保留幂等标识，阻止双击重复提交；身份改变或撤权清除私有内容并中止旧写入回调。

## 验收方式与边界

自动化测试使用隔离数据库、确定性模型替身；不能据此宣称本轮完成了真实海外资料采集或四角色外部模型研究。正式数据库仅在部署迁移及明确记录的浏览器操作中使用。原有 Google 研究不因本轮验证自动重试、取消或更改范围。

当前 Google / Alphabet 研究存在已确认的来源覆盖和主体准入缺口：原任务为海外公司，但现有采集适配器偏国内来源；现有冻结范围与 Alphabet 来源名存在匹配问题。公司档案不会放宽这些证据规则，也不能把零准入证据包装为完成研究。

资料入口当前支持粘贴待核验文本及来源说明，并进入现有真实采集研究流程；文件上传、PDF 解析和资料库批量导入仍需专门实现。持续研究历史背景为有标记的节选，后续应补结构化经营假设、指标变化及反证对照，避免只依靠摘要比较。

当前历史来源授权最多检查 32 个研究节点；更深的连续采用链会明确阻止继续沿用历史背景，而不是跳过来源复核。长期使用需增加保留完整来源依赖的检查点机制。

## 后续修改建议（按优先级）

1. 为海外公司建立可验证的市场 / 主体 / 来源路由：保留用户标识和来源确认的法律实体 / 别名区别，用来源匹配证据修正下一次研究范围，不能直接修改已冻结历史任务。
2. 建立可追溯的资料摄取入口：文件原文、页码、哈希、期间和来源许可形成可准入证据；粘贴文本保留“用户提供、待核验”状态。
3. 在公司采用版本之上增加经营假设与指标台账，明确“维持、变化、反证、待核验”，每一变化绑定新旧证据及确切模型输出；不自动覆盖人工判断。
4. 增加监控结果的无变化判定、主题去重和可见预算 / 调用记录，区分调度成功、采集成功、证据准入、四角色完成与人工采用。
5. 为超过 32 个节点的采用历史设计可验证检查点，保留跨版本撤权依赖，避免深历史阻止持续研究。
6. 持续监测容器探针耗时、任务租约恢复和数据库查询成本；避免轮询与健康检查本身成为运行负担。

- 浏览器创建真实公司档案“谷歌 / Alphabet”（美国、未填证券代码），并关联用户已有谷歌事件研究。公司 ID：`9802bd7a-e8ae-40fd-8b47-15fa454ff6ed`；原会话 `82c9c4bf-a8e6-415e-be64-e8baca3f9798`，run spec `62bd7e46-e3e5-4007-abf4-49dbc1efed9c`。重开页面后仍保存。

### 断网、恢复及来源撤权的最后验证

- 暂态网络错误、超时、HTTP 408 / 429 / 5xx 保留相同身份及授权范围内的上次团队数据，显示“上次读取 / 团队状态待更新”，同时禁止提交、控制命令、重试写入和人工复核。
- 401 / 403 / 404、schema 错误、确定性错误、身份或范围变化仍清除；来源原文或任务历史返回 404 时，通过统一回调同步清除团队缓存，后续 503 不能恢复旧内容。
- 此策略符合已确认的同权限刷新契约；独立安全复核运行 142 项测试通过。最终全量前端 330 项通过，生产镜像内 TypeScript / Vite 构建通过。
- 在独立 `localhost:5181` 临时前端容器中访问同一私有研究，只执行 GET；先暂停容器的采样未捕获到失联状态，因此该轮不作为断网禁写证明。随后停止该临时前端 35 秒并重新读取团队，实际观察到四角色仍在、协作时间线仍选中、草稿保留，且“恢复 / 取消 / 提交”均禁用，显示明确待更新提示。
- 临时前端自动重启后，观察到四角色、选中标签与原草稿仍保留，待更新提示消失，提交重新启用；没有提交验收草稿或调用模型。
- 正式 5180 前端已更新为通过该验收的镜像。临时浏览器页已关闭，临时前端容器已删除；正式 API / 数据库 / workers 在故障测试期间继续运行。

- 搜索真实过滤研究线程标题，有零结果提示；缩小占位文字承诺范围。
- 筛选计数从当前示例数据推导。仅看待办过滤进行中与待审核任务；目标、任务、审核标签与所选记录吻合。筛选后时间戳保持记录对应关系。
- 证据页签使用单一 Tab 停靠点，支持左右箭头、Home、End，并关联对应面板。筛选按钮提供选中语义，折叠按钮提供展开状态。
- 移动端与平板取消 hover/focus 抽屉，改为页面内堆叠；补充输入容器焦点、面板焦点及 reduced-motion。长消息可换行。
- 移除 index.html 中指向不存在 main-content 的重复跳转链接；保留组件内 workspace 链接并使主内容可聚焦。

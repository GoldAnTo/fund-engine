# 研报工作台视觉盘点

本页记录已批准的研报优先工作台构图，供后续改动审计；它不是运行时素材，也不使用图像生成结果作为 UI 资源。

## 必须保留

- 纸张色主背景、石墨色细分隔线，只有行动和安全链接使用低饱和蓝色强调。
- 首屏先给出当前判断、关键缺口和下一步，而非仪表盘指标或聊天输入。
- 桌面采用不等宽的两列案头布局：主张/证据为主阅读列，因素判断为辅助列；避免同尺寸卡片网格。
- 1D、5D 市场窗口紧随证据，混杂因素以文字状态（已排除、仍待评估、重大替代解释）列出。
- 资产区分别解释传导公司、可映射 A 股和基金覆盖；缺数据直接显示不可计算。
- 图谱放在工作台之后，桌面图谱与结构化路径/检查器并列；图谱只用于定位路径，不作为可信度证明。
- 390px 默认给出结构化路径，SVG 隐藏且页面无横向溢出。

## 明确不采用

- 渐变文字、玻璃拟态、彩色侧栏、营销式 KPI 卡片、装饰性关系图。
- 把原始 locator、UUID、任务/run/proposal JSON 当作读者内容。
- 在无数据时填充价格、持仓、覆盖度或结论。

## 可审计检查

- `frontend/e2e/report-research.spec.ts` 维护桌面和 390px `toHaveScreenshot` 基线。
- 组件测试验证来源仅显示安全 URL 或人话定位、混杂因素状态、资产不可计算文案和键盘可访问路径。
